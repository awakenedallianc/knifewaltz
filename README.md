# 刀尖舞 KnifeWaltz

**纪律是唯一的刀鞘。** 在坠落里找秩序。

全网唯一敢把每一次接飞刀公开记账的金融频道：每把刀有机读规则、明码仓位、认错线，
胜率和败率一起挂在首页——别人卖恐慌，我们结算恐慌。

站点：https://awakenedallianc.github.io/knifewaltz/

## 是什么

- **市场闸门**：VIX 三档恐慌闸（36 年历史现算回测）、期限结构倒挂/翻正、自算广度洗仓、加密恐惧
- **刀落板**：T1 白名单（指数/大宗/BTC）+ S&P 500 池 -60% 动态扫描，5 状态机 + KnifeScore + 10 日接刀窗
- **双口径诚实统计**：同一信号给两套成绩单——持有一年（学术口径）与含止损重放（执行口径），胜率永远带 Wilson 区间和最差一次
- **结算台账**：36 年回测逐笔 + 实盘信号自上线日逐笔追加，亏损与盈利同字号
- **仓位计算器**：1/4 Kelly × 连败倒推双封顶（硬顶 2%），负期望直接拒绝输出；先立预承诺才能用
- **刀谱**：18 例历史崩盘现场重算（A 族流动性休克 / B 族泡沫出清），含「-30% 买点还要再挨几刀」

## 不是什么

不是投资建议。不收费、不设群、不代客。运行时零大模型，全部数据来自免费公开接口，
每个数字可点击徽章回到原始数据源复算。

## 运行

```
pip install -r requirements.txt
python run.py                # 全量：抓数 → 引擎 → 重放 → 台账 → 渲染 docs/
python run.py --build-only   # 只重建站点
```

GitHub Actions 每日两跑（06:37 / 18:37 曼谷时间），状态文件（台账/状态机）提交回 `data/state/` 实现跨跑批持久化。
